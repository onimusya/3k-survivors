# Taste
- Break work into the smallest independently improvable and judgeable pieces; iterate each with a builder plus a separate, harsh critic using fresh context. The critic must never trust the builder's summary and must validate empirically in a headless browser at a mobile viewport with real screenshots, pixel inspection, and game feel. Confidence: 0.95
- Use sub-agents heavily when available; if the harness has none, run the rounds yourself across turns. Never build an agent framework, orchestrator, or SDK integration, and never ask for an API key to spawn agents. Confidence: 0.95
- Maintain a single auto-refreshing `progress.html` in the project root (`<meta http-equiv="refresh" content="10">`) with project name, phase, last-updated time, stat cards, per-piece state/rounds/score/biggest gap, and an append-only timestamped activity log. Update it every working turn and record failures/blockers immediately. Confidence: 0.95
- When a command fails twice with the same error, do not run it a third time; write the command, error, and intended alternative into notes on disk, then change approach. Confidence: 0.95
- Where the brief leaves a choice (metric, hyperparameter, architecture, format), decide it yourself, record the choice and rationale, and continue without asking for approval. Confidence: 0.95
- Stop only when proceeding is impossible because a stated thing does not exist or would break a stated constraint; then ask one specific question. Treat two rounds with no artifact change and no score reported as a stall: document the blocker and change approach. Confidence: 0.95
- Keep looping until the work wins a blind side-by-side comparison against Vampire Survivors screenshots/wiki mechanics, with the critic stating which is better and why. Confidence: 0.9
- Use PixiJS for 2D mobile web game rendering. Confidence: 0.8
- For this game, hold a locked 60 FPS with 300+ active enemies on screen. Confidence: 0.85
- Any evaluation harness must print, on the same line as a score: the model score, constant-predictor score, random-predictor score, and training/evaluation label distributions. A harness missing any of these is incomplete. Confidence: 0.9
